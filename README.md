🍵 Mistvale Tea Co. — Premium Tea Store
A modern, responsive e-commerce website for Mistvale Tea Co., built as a frontend-focused shopping experience with product discovery, filtering, cart management, coupons, shipping calculation, and checkout flow.
✨ Features
- 🛍️ Product listing and product details
- 🔎 Product search
- 🏷️ Category filtering
- ↕️ Product sorting
- 👀 Quick View for products
- 🛒 Add to cart
- ➕➖ Increase/decrease product quantity
- 🗑️ Remove products from cart
- 🚫 Sold-out product handling
- 🎟️ WELCOME10 coupon support
- 🚚 Shipping calculation
- 📍 Pincode validation
- 📧 Newsletter subscription UI
- 💳 Checkout flow
- 📱 Fully responsive design
- ⌨️ Keyboard-friendly interactions
- ♿ Accessibility-focused implementation
- 🔍 SEO metadata and structured data
- 💾 Cart/state persistence using LocalStorage
🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
- Google Fonts
- LocalStorage
- REST/API integration

🛒 Shopping Experience
Users can:
1. Browse tea products.
2. Search products.
3. Filter by category.
4. Sort products.
5. Open Quick View.
6. Add products to cart.
7. Update quantities.
8. Remove products.
9. Apply the available coupon.
10. Check shipping information.
11. Validate pincode.
12. Continue through checkout.
